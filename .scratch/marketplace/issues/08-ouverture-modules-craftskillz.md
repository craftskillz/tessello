# 08: Ouverture avec les Modules de @craftskillz

Spec parente : `.scratch/marketplace/spec.md`. Vocabulaire : `GLOSSARY.md`. Décisions : ADR 0014 à 0018. Contrat : la Convention.

**What to build:** La Marketplace ouvre avec Diagram, Watch Later et Survival Kit, publiés sous `@craftskillz` par le parcours normal des Créateurs.

**Blocked by:** 05, 07, ticket 20 de tessello-v1 (renommage sous `@craftskillz`)

**Status:** ready-for-human

- [ ] Les `.zip` des trois Modules sont hébergés sur GitHub Pages, une URL par version.
- [ ] Une pull request par Module, ouverte par le compte `craftskillz`, passe la CI ; le Mainteneur l'approuve.
- [ ] Les trois Modules s'installent depuis l'écran Marketplace d'un Hôte déployé, et depuis le bouton du site.
- [ ] Les Modules d'exemple (`examples/` : notes, meteo, prometheus) ne sont pas publiés.
