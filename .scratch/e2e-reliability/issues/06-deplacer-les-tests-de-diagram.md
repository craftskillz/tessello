# 06 : Diagram : déplacer ses tests

**Status:** ready-for-human

**Blocked by:** 02 — Mesurer ; 04 — Un Hôte de test dans le SDK ; 05 — Les tests de contrat des Modules dans l'Hôte.

Spec parente : [des tests navigateur rapides et fiables](../spec.md). Table de référence : `.scratch/e2e-reliability/audit.md`, section Diagram.

**What to build:** Les 45 tests navigateur de `packages/host/e2e/diagram.test.ts` quittent ce dépôt selon l'audit. Ses règles sont prouvées dans `../tessello-diagram` par des tests unitaires, ou par une petite suite navigateur contre l'Hôte de test. Il ne reste ici que ses tests de contrat (ticket 05), et ceux que l'audit classe « Hôte ».

Notes pour ce Module : Les gestes de pointeur (tirer une flèche, poignées, groupes, rotation, panoramique et zoom) relèvent sans doute de sa suite navigateur ; l'export `.drawio`, l'historique, la géométrie des extrémités et les valeurs par défaut ont déjà des tests unitaires (`drawio`, `history`, `arrows`, `geometry`, `defaults`) à confronter à l'audit. L'export PNG et le presse-papiers d'images demandent un vrai navigateur. L'échec CI `diagram.test.ts:1143` disparaît avec ce ticket.

Le résultat (test, modification faite, échec observé) est noté dans `audit.md`, en face de la ligne. Une ligne « déjà couvert » est vérifiée de la même façon sur le test cité.
- [x] Le workflow de CI du Module (s'il y en a un, sinon un nouveau) lance ses tests unitaires et sa suite navigateur à chaque push. `just publish` du Module les lance aussi avant de publier.
- [x] Dans ce dépôt : les tests déplacés sont supprimés de `packages/host/e2e/diagram.test.ts`, ou le fichier entier s'il n'y reste rien, avec les utilitaires qui ne servent plus. Les tests de contrat et les tests « Hôte » restent.
